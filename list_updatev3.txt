============================================================
FITUR KHUSUS ELF BINARY (32/64 BIT)
============================================================

1. ELF HEADER PARSER (LENGKAP)
   - Tampilkan semua field: e_type, e_machine, e_version, e_entry, e_phoff, e_shoff, e_flags, e_ehsize, e_phentsize, e_phnum, e_shentsize, e_shnum, e_shstrndx
   - Deteksi arsitektur (ARM/ARM64/x86/x86_64)
   - Deteksi endianness (little/big)
   - Tampilkan interpretasi human-readable (contoh: "Executable file for ARM64")

2. PROGRAM HEADER (SEGMENT) VIEWER
   - Tampilkan semua segment: PT_LOAD, PT_DYNAMIC, PT_INTERP, PT_NOTE, dll
   - Kolom: Type, Offset, VAddr, PAddr, FileSz, MemSz, Flags, Align
   - Warna: executable (hijau), writable (merah), read-only (biru)

3. SECTION HEADER VIEWER
   - Tampilkan semua section: .text, .data, .rodata, .bss, .symtab, .strtab, .dynsym, .dynstr, .got, .plt, dll
   - Kolom: Name, Type, Address, Offset, Size, EntSize, Flags, Link, Info, Align
   - Filter: tampilkan cuma executable, cuma writable, cuma debug, dll

4. SYMBOL TABLE (.symtab & .dynsym)
   - Tampilkan semua symbol (fungsi, variabel, objek)
   - Kolom: Num, Value, Size, Type, Bind, Vis, Ndx, Name
   - Warna: FUNC (hijau), OBJECT (kuning), NOTYPE (abu-abu)
   - Search + filter by name/type/bind
   - Click symbol → langsung ke alamat di disassembler

5. DYNAMIC SECTION (.dynamic)
   - Tampilkan semua DT_* entries: DT_NEEDED, DT_SONAME, DT_RPATH, DT_RUNPATH, DT_INIT, DT_FINI, dll
   - Tampilkan library dependencies (DT_NEEDED)
   - Tampilkan init/fini functions

6. RELOCATION (.rel.dyn, .rel.plt, .rela.dyn, .rela.plt)
   - Tampilkan semua relokasi: offset, type, symbol, addend
   - Tampilkan tipe relokasi (R_ARM_*, R_AARCH64_*, R_X86_64_*)
   - Tampilkan alamat yang di-relokasi + nilai akhir

7. GOT & PLT
   - Tampilkan GOT (Global Offset Table) entries
   - Tampilkan PLT (Procedure Linkage Table) stub
   - Tampilkan resolved address (jika ada)

============================================================
FITUR KHUSUS SHELL SCRIPT (.sh) YANG BERISI BINARY
============================================================

8. SHELL SCRIPT PARSER
   - Deteksi shell script (shebang #!/bin/bash, #!/bin/sh, dll)
   - Ekstrak metadata: interpreter, encoding, line count, size
   - Tampilkan struktur: shebang, komentar, variable, function, payload

9. BINARY EXTRACTOR DARI SHELL SCRIPT
   - Deteksi binary terenkapsulasi (base64, hex, uudecode, gzip, tar, dd)
   - Ekstrak otomatis ke /tmp/ dengan nama asli
   - Support: base64 -d, xxd -r, uudecode, gunzip, tar -x
   - Tampilkan: posisi offset mulai, ukuran binary, tipe kompresi
   - Setelah ekstrak → langsung analisis binary dengan ELF parser

10. SHELL SCRIPT DEOBFUSCATOR
    - Deteksi string obfuscation: base64, hex, ROT13, caesar, XOR, shell escape (\xXX), eval
    - Decode otomatis semua obfuscated string
    - Tampilkan hasil decode inline (komentar)
    - Export hasil deobfuscated ke file baru

11. SHELL SCRIPT PATCHER
    - Edit field: ubah URL, IP, key, token, path
    - Ganti fungsi/command: curl → echo (bypass network), wget → echo
    - Patch license check di shell script (ubah kondisi if)
    - Simpan sebagai file baru

12. SHELL SCRIPT ANALYZER
    - Tampilkan semua command yang dipanggil (curl, wget, chmod, systemctl, dll)
    - Tampilkan semua URL/IP/domain yang muncul
    - Tampilkan semua key/token/license yang muncul
    - Tampilkan dependency (file yang dibutuhkan)
    - Tampilkan flow graph sederhana (if/else/for/while)

============================================================
FITUR DISASSEMBLER (KHUSUS ELF)
============================================================

13. DISASSEMBLER (Capstone Native)
    - Support ARM32 (ARM/Thumb/Thumb-2)
    - Support ARM64 (AArch64)
    - Support x86/x86_64
    - Tampilkan: address, hex bytes, mnemonic, operands
    - Warna: opcode (cyan), mnemonic (hijau), operand (putih), comment (abu-abu)

14. DISASSEMBLE SECTION
    - Disassemble seluruh .text section
    - Tampilkan function boundaries (dari symbol table)
    - Label fungsi otomatis

15. DISASSEMBLE FUNCTION
    - User pilih fungsi dari symbol table
    - Tampilkan disassembly fungsi dari start sampai end
    - Tampilkan control flow (basic block)

16. DISASSEMBLE ADDRESS
    - User input alamat → disassemble 10 instruksi di sekitarnya
    - Tampilkan XREF ke alamat ini

17. DECOMPILER (Pseudo-C)
    - Gunakan r2ghidra atau Ghidra decompiler (native)
    - Tampilkan pseudo-C dari fungsi yang dipilih
    - Tampilkan variable names, function calls, loop, if-else

============================================================
FITUR MEMORY DUMP & SEARCH
============================================================

18. MEMORY DUMP ANALYZER (KHUSUS ELF)
    - Baca raw dump memory
    - Deteksi alamat base (cari ELF header)
    - Tampilkan region memory: text, data, stack, heap
    - Ekstrak string dari dump
    - Ekstrak pointer dari dump

19. PATTERN SEARCH (ADVANCED)
    - Cari hex pattern: "7F 45 4C 46" (ELF magic)
    - Cari text pattern: "password", "token", dll
    - Cari regex: URL, IP, email, GUID
    - Cari instruction pattern: "mov x0, x1" (pakai Capstone)

============================================================
FITUR PATCHING (KHUSUS ELF & SHELL SCRIPT)
============================================================

20. PATCH INSTRUCTION (ELF)
    - Ubah opcode di alamat tertentu
    - Pilih instruction baru dari dropdown (NOP, RET, JMP, dll)
    - Preview perubahan (sebelum vs sesudah)
    - Simpan ke file baru

21. PATCH BRANCH (ELF)
    - Deteksi instruksi conditional: JNE, JE, JZ, JNZ, CBNZ, CBZ, dll
    - Ubah jadi unconditional JMP
    - Ubah jadi NOP
    - Ubah jadi RET (return 0)

22. AUTO PATCH LOGIN BYPASS (ELF)
    - Cari string "Wrong", "Invalid", "Login Failed"
    - Cari XREF ke string tersebut
    - Trace branch di sekitarnya
    - Sarankan patch: JNE→JMP atau RET 0
    - One-click apply

23. PATCH STRING (ELF)
    - Ganti string di .rodata / .data
    - Support: ASCII, UTF-16, Unicode
    - Jika string baru lebih pendek → sisanya NOP/null
    - Preview sebelum-sesudah

24. PATCH SHELL SCRIPT
    - Ganti URL/IP/domain di shell script
    - Ganti key/token/license
    - Ganti command: curl → echo (bypass network)
    - Patch if condition: if [ "$KEY" == "xxx" ] → if [ "$KEY" != "xxx" ]

============================================================
FITUR DEOBFUSCATE (KHUSUS ELF & SHELL SCRIPT)
============================================================

25. STRING DEOBFUSCATE (ELF)
    - Scan semua string di .rodata / .strtab
    - Deteksi: Base64, Hex, XOR, Unicode, URL encode, Reverse, ROT13
    - Tampilkan raw + decoded
    - Tombol "Apply to File" → patch binary

26. XOR BRUTE FORCE
    - Brute force key 0x00-0xFF untuk string yang di-XOR
    - Tampilkan hasil terbaik (entropy rendah)
    - Auto detect key

27. AUTO DEOBFUSCATE (ELF)
    - Scan semua string
    - Detect tipe obfuscation (Base64/Hex/XOR/dll)
    - Decode otomatis semua
    - Patch semua ke binary

28. SHELL SCRIPT DEOBFUSCATE
    - Scan semua string di shell script (grep, sed, awk)
    - Deteksi obfuscation: base64, hex, ROT13, eval, shell escape
    - Decode inline (ganti dengan hasil decode)
    - Export ke file baru

============================================================
FITUR ANTI-ANTI-DEBUG (KHUSUS ELF)
============================================================

29. DETEKSI ANTI-DEBUG
    - Cek TracerPid: grep TracerPid /proc/self/status
    - Cek ptrace: ptrace(PTRACE_TRACEME, 0, 0, 0)
    - Cek /proc/self/maps
    - Cek frida detection: file /proc/self/fd
    - Cek gdb detection: /proc/self/status

30. PATCH ANTI-DEBUG
    - Patch TracerPid check → return 0
    - Patch ptrace check → return 0
    - Patch frida detection → NOP
    - Patch gdb detection → NOP
    - One-click bypass

============================================================
FITUR PACKER DETECTION (KHUSUS ELF)
============================================================

31. DETEKSI PACKER
    - UPX: cek string "UPX!" di section
    - Themida: cek entropy tinggi + section aneh
    - OLLVM: cek banyak NOP + control flow flattening
    - Deteksi berdasarkan entropy
    - Deteksi berdasarkan compressed section

32. UNPACKER (OTOMATIS)
    - UPX: jalanin `upx -d` (if installed)
    - Manual unpack: dump memory saat runtime
    - Support: UPX, Themida (basic), OLLVM (basic)

============================================================
FITUR INTEGRASI TERMINAL (KHUSUS ELF)
============================================================

33. READELF COMMAND
    - Jalankan readelf -h (header)
    - Jalankan readelf -S (sections)
    - Jalankan readelf -s (symbols)
    - Jalankan readelf -d (dynamic)
    - Tampilkan output di terminal

34. OBJDUMP COMMAND
    - Jalankan objdump -d (disassembly)
    - Jalankan objdump -t (symbols)
    - Jalankan objdump -x (all headers)
    - Tampilkan output di terminal

35. STRINGS COMMAND
    - Jalankan strings -n 4 (min 4 chars)
    - Jalankan strings -t x (with offset)
    - Tampilkan output di terminal
